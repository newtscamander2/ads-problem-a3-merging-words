\section*{Comment}

\section*{a)}
We let M[i,j] denote the boolean value that is true if and only if $z_1 z_2 ... z_{i+j}$ is a merge of $x_1 x_2 ... x_{i}$ and $y_1 y_2 ... y_{j}$. We can use the recurrence $M[i,j]$ to fill out the table.

\begin{equation}
	M[i,j] = \begin{cases}
		true                                                              & \text{if } i=0 \land j=0   \\
		z_j = y_j \land M[0,j-1] \                                        & \text{if } i=0 \land j > 0 \\
		z_i = x_i \land M[i-1,0] \                                        & \text{if } i>0 \land j = 0 \\
		(z_{i+j} = y_j \land M[i,j-1]) \lor (z_{i+j} = x_i \lor M[i-1,j]) & \text{if } i>0 \land j > 0
	\end{cases}
	\label{piecewise}
\end{equation}

We can fill out the table with $x, y$ and z.

\begin{align}
	x & = SHOE     \\
	y & = EARS     \\
	z & = SEAHORSE \\
\end{align}

	\begin{tabular}{c  c | c c c c c}
		  &        & y & E & A & R & S \\
		  & M[i,j] & 0 & 1 & 2 & 3 & 4 \\

\end{center}

\section*{b)}
To dynamically find out if the word \variable{z} is the merge of two words \variable{x}, \variable{y}, we have to create a table of the words. We go from left to right finding the answers for the previous inputs.

The different if-statements are made from the piecewise-function given in \bookeq{\ref{piecewise}}.

\begin{pseudo}[span]
	function Is-Merge(M, x, y, z, i, j)
	if i == 0 and j == 0 then
	M[i,j] = true

	return true
	end

	for a = 0 -> j //Bottom up programming :)
	for b = 0 -> i
	Merge(M, x, y, z, b, a)
	end
	end

	if i == 0 and j > 0 then
	M[i,j] = z_j == y_j and z_j == M[0,j-1]

	return M[i,j]
	end

	if i > 0 and j == 0 then
	M[i,j] = z_i == x_i and z_i == M[i-1,0]

	return M[i,j]
	end

	if i > 0 and j > 0 then
	M[i,j] = (z_{i+j} == y_j and z_{i+j} == M[i,j-1]) and (z_{i+j} == x_i and z_{i+j} == M[i-1,j])

	return M[i,j]
	end
	end
\end{pseudo}
The \method{Is-Merge} function runs through every letter in both \variable{x} and \variable{y}. It is therefore $O(n+m)$ where $n$ is the length of \variable{x} and $m$ is the length of \variable{y}.
