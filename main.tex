\section*{Comment}

\section*{a)}
We let M[i,j] denote the boolean value that is true if and only if $z_1 z_2 ... z_{i+j}$ is a merge of $x_1 x_2 ... x_{i}$ and $y_1 y_2 ... y_{j}$. We can use the recurrence
test
\begin{equation}
	M[i,j] = \begin{cases}
		true                                                               & \text{if } i=0 \land j=0   \\
		z_j = y_j \land M[0,j-1] \                                         & \text{if } i=0 \land j > 0 \\
		z_i = x_i \land M[i-1,0] \                                         & \text{if } i>0 \land j = 0 \\
		(z_{i+j} = y_j \land M[i,j-1]) \lor (z_{i+j} = x_i \land M[i-1,j]) & \text{if } i>0 \land j > 0
	\end{cases}
	\label{piecewise}
\end{equation}

\begin{pseudo}[span, from=java]
	String x = " SHOE";
	String y = " EARS";
	String z = " SEAHORSE";

	boolean[][] M = new boolean[x.length()][y.length()];

	for(int i = 0; i < M.length; i++)
	for(int j = 0; j < M[i].length; j++)

	if(i == 0 && j == 0)
	M[i][j] = true;

	if(i == 0 && j > 0)
	M[i][j] = z.charAt(j) == y.charAt(j) && M[0][j - 1];

	if(i > 0 && j == 0)
	M[i][j] = z.charAt(i) == x.charAt(i) && M[i - 1][0];

	if(i > 0 && j > 0)
	M[i][j] = (z.charAt(i + j) == y.charAt(j) && M[i][j - 1]) ||
	(z.charAt(i+j) == x.charAt(i) && M[i-1][j]);

\end{pseudo}

\section*{b)}
To dynamically find out if the word \variable{z} is the merge of two words \variable{x}, \variable{y}, we have to create a table of the words. We go from left to right finding the answers for the previous inputs.

The different if-statements are made from the piecewise-function given in \bookeq{\ref{piecewise}}.

\begin{pseudo}[span]
	function Is-Merge(M, x, y, z, i, j)
	if x_length + z_length != z_length then
		return false
	end

	if i == 0 and j == 0 then
	M[i,j] = true

	return true
	end

	for a = 0 to j-1 do //Bottom up programming :)
	for b = 0 to i-1 do
	Is-Merge(M, x, y, z, b, a)
	end
	end

	if i == 0 and j > 0 then
	M[i,j] = z_j == y_j and M[0,j-1]

	return M[i,j]
	end

	if i > 0 and j == 0 then
	M[i,j] = z_i == x_i and M[i-1,0]

	return M[i,j]
	end

	if i > 0 and j > 0 then
	M[i,j] = (z_{i+j} == y_j and M[i,j-1]) or (z_{i+j} == x_i and M[i-1,j])

	return M[i,j]
	end
	end
\end{pseudo}
The \method{Is-Merge} function runs through every letter in both \variable{x} and \variable{y}. It is therefore $O(nm)$ where $n$ is the length of \variable{x} and $m$ is the length of \variable{y}.

In the pseudo code we have defined a function called \method{Is-Merge-Constituted}. It is a modification of \method{Is-Merge} but with some important differences. Essentially, \method{Is-Merge} is extended to also report the indexes of z that constitute the subsequence of equal to x.

As it can be seen below the recursive call is changed to \method{Is-Merge-Constituted} instead of \method{Is-Merge}. We create a new array called B that is initially empty. When $i>0$ and $j==0$ we modify $M[i,j]$ as we did before but we also check that if $M[i,j]==true$ then we set $M[i,j]$ to true as well!

Furthermore, if both $i>0$ and $j>0$ we still modify $M[i,j]$ and

\begin{pseudo}[span]
	function Is-Merge-Constituted(M, B, x, y, z, i, j)
	if x_length + z_length != z_length then //If the lengths of x and y are not the same, then it cannot be a merge of the two...
		return false
	end

	if i == 0 and j == 0 then
	M[i,j] = true
	return true
	end

	for a = 0 to j-1 do //Bottom up programming :)
	for b = 0 to i-1 do
		Is-Merge-Constituted(M, B, x, y, z, b, a)
	end
	end

	if i == 0 and j > 0 then
	M[i,j] = z_j == y_j and M[0,j-1]
	return M[i,j]
	end

	if i > 0 and j == 0 then
	M[i,j] = z_i == x_i and M[i-1,0]

	//Track B
	if M[i,j] == true then
	B[i] = true;
	end

	return M[i,j]
	end

	if i > 0 and j > 0 then
	M[i,j] = (z_{i+j} == y_j and M[i,j-1]) or (z_{i+j} == x_i and M[i-1,j])

	//Track B
	if M[i,j] == true and z_{i+j} == x_i then
	B[i+j] = true;
	end

	return M[i,j]
	end
	end

	function Print-Merge(x, y,z)
	Is-Merge = Is-Merge-Constituted(M, B, x, y, z, x_length, y_length)

	//Go through B and print if it is seen as a merge.
	if Is-Merge then
	for n = 1 -> z_length do
	if B[n] then
	//Print
	print(n)
	end
	end
	end

	end
\end{pseudo}
